# SnipUrl - Modern URL Shortener & Link Intelligence

SnipUrl is a high-performance URL shortening and link telemetry platform built with React, Vite, Tailwind CSS, and Chart.js.

## ✨ Features

- **Lightning-Fast Shortening**: Transform long URLs into concise, branded short links.
- **Granular Link Analytics**: Real-time click tracking and visual telemetry charts.
- **Enterprise Security**: HTTPS redirect encryption and safe destination verification.
- **Modern Glassmorphic UI**: High-end user interface crafted with Tailwind CSS and Framer Motion.
- **Interactive Dashboard**: Direct link copy, telemetry inspection, and link lifecycle management.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
